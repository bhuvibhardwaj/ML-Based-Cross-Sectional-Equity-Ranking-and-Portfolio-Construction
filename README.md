# ML-Based Cross-Sectional Equity Ranking

An implementation-focused academic project for monthly stock ranking and portfolio
evaluation. The  checked-in evaluation panel covers 19 stocks from February 2016 through
November 2024.

## Implemented pipeline

- 13 features derived from daily OHLCV data.
- Three ranking models: Ridge Regression, XGBoost Regression, and XGBoost
  Learning-to-Rank.
- Chronological train, validation, and test splits.
- Monthly equal-weighted Top-5 portfolio simulation with turnover and assumed trading
  costs.
- A seven-page interactive dashboard backed by CSV results in `results/`.

The checked-in market comparator is a liquidity-weighted proxy from the same 19 stocks,
not an official Nifty 50 index series. Data files do not identify whether they were
downloaded or generated by the fallback, so provenance is unverified.

## Setup and run

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run_pipeline.py
streamlit run app.py
```

Run the tests and consistency checks with:

```bash
python -m pytest -q
python tests/qa_cross_page_consistency.py
python tests/qa_app_pages.py
```

See `REPORT.md`, `docs/methodology.md`, and `docs/final_report.md` for the implemented
methodology, assumptions, and evaluation scope.
